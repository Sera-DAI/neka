# Fontes das imagens

As imagens desta pasta são geradas por `scripts/gerar_imagens.py` (identidade "Algodão-Doce", a mesma do Kotsu e da CLI).

- O título "neka" no banner usa as letras da **Inter Display Bold** (Rasmus Andersson), convertidas em
  contorno no SVG. Licença SIL Open Font License 1.1 (<https://openfontlicense.org>).
- Os ícones das tecnologias vêm do Simple Icons (CC0, <https://simpleicons.org>); o do Claude foi
  copiado do Kotsu, no mesmo estilo. As marcas pertencem aos respectivos donos e aparecem só para indicar o que o projeto usa.
- Os corações, brilhos, divisores e ícones de seção foram desenhados para este projeto. Os dados que aparecem no terminal do banner são fictícios.
