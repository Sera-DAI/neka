# Image sources

The images in this folder are generated by `scripts/generate_images.py` ("Cotton Candy" identity, the same as Kotsu and the CLI).

- The "neka" title in the banner uses the letters of **Inter Display Bold** (Rasmus Andersson), converted
  to outlines in the SVG. License: SIL Open Font License 1.1 (<https://openfontlicense.org>).
- The technology icons come from Simple Icons (CC0, <https://simpleicons.org>); the Claude one was
  copied from Kotsu, in the same style. The brands belong to their respective owners and appear only to show what the project uses.
- The hearts, sparkles, dividers and section icons were drawn for this project. The data shown in the banner terminal is fake.
